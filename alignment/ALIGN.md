# ALIGN — 与官方对齐协议

对齐官方是本 skill 的唯一北极星。本文件规定怎么把"对齐"从口号变成可执行的采集、
比对与复盘回路。**对齐的对象是裁决，不是措辞**：同一个局面，我们和官方做了同样的
取舍，才叫对齐；措辞相似度是副产品。

---

## §1 语料库规范

每个采集 case 落盘 `alignment/corpus/{case_id}/`：

```
case_id/
├── input/           # 指令原文 + 全部素材文件
├── official_ir.txt  # T9 取回的官方输出（原样）
├── our_draft.md     # 我方 P0–P4 裁决草稿（比对时后补）
├── our_ir.txt       # 我方终稿
└── verdict_diff.md  # §3 比对产物
```

case_id 命名编码探针意图：`{探针族}-{变量}-{序号}`，如 `B3-dress_transfer-02`。
同一探针族内**只动一个变量**——对照实验是逆向裁决策略的唯一可靠方法，
一次动两个变量的采集作废。

## §2 探针队列（按 case_law 缺口排定，普通 agent 照单执行）

预算基准：每族 3–6 次调用即可定一条规则，全队列 ≈ 60–100 次官方 API 调用。

| # | 探针族 | 回答的问题 | 对应缺口 | 优先级 |
| --- | --- | --- | --- | --- |
| 2 | 部分引用 | 要裙子不要人：来源载体是否零残留 | case_law B-3 | **最高** |
| 3 | 引用歧义梯度 | 指令从明确到欠定，默认引用面怎么收缩 | B-4 | 高 |
| 1 | 音频截断 | 长音频进短视频，截哪、怎么登记 | A-5 | 高 |
| 5 | 补全深度 | 极简指令下官方补到哪层停手 | C-3 | 高 |
| 4 | 版式/文字 | logo 与海报的束拆分与运动语汇 | B-5 | 中（商用主场）|
| 6 | 风格词 | 单变量风格词 → 物理参数 diff | §D 全表 | 中 |
| 7 | 语速常数 | 量官方成片回归各语言词/秒 | E-2 | 中（不耗API）|
| 8 | 冲突仲裁 | 素材互斥（图光线 vs 视频场景）谁让位 | P3 判据 | 中 |
| 9 | 否定指令 | "镜头别动/不要配乐"如何落成正面措辞 | P1 纪律 | 低 |
| 10 | 超载砍词 | 台词超时长，官方砍哪句 | P3 仲裁顺序 | 低 |
| 11 | 配乐措辞冲突 | mood 词在何种物理描述密度下被官方保留 | F-1 / Base Guide §4.7 | 中 |

探针输入的构造纪律：素材用自有/可商用来源；每个探针族先写"预期官方裁决"再调 API——
**预测错了的探针比预测对的值钱十倍**，它暴露的是我们裁决模型的系统性偏差，
在对应 case 的 `verdict_diff.md` 中单独记录为 surprise。

## §3 裁决一致性比对（IR 层，主战场）

对每个 case，先由我方 skill **盲跑**（执行者不得先看 official_ir.txt），再做双向比对。
比对不打总分，逐维度记 `一致 / 分歧 / 我方缺失 / 官方缺失`：

1. **任务类型判定**：editing / ref generation / continuation / audio reuse / audio
   reference 的组合是否相同——这是最上游裁决，错则全错
2. **引用面**：逐属性束比 cite/discard/transfer 三选一。特别盯 discard：
   官方没写的东西我们写了没有（全保病），我们 discard 的官方是否其实保了
3. **仲裁结果**：冲突/超载各条的牺牲对象是否一致
4. **时间轴叙事**：镜头数、每个 cut 的踩点类型（句隙/节拍/动作点/揭示）、
   每镜头戏剧功能是否同构——不要求毫秒相同，要求**理由同类**
5. **补全半径**：我方补的内容里有多少落在官方补全半径之外（越界）、
   官方补了而我方没补的质感层（不足）
6. **护栏密度**：phrasebook 各触发条件下，官方写了护栏而我方漏写的次数（裸奔计数）

产出 `verdict_diff.md`。**每一处分歧强制三选一归因**：
`(a) case_law 缺规则 → 开新判例` / `(b) 有规则但执行漏了 → 修 SKILL.md 流程` /
`(c) 官方此处自身不稳定 → 同探针重采一次确认`。
归因 (a) 的判例入库后，**必须重新盲跑同 case 验证分歧消除**，才算闭环。

## §4 终审（成片层，T11 可用时）

IR 层一致不保证成片一致——护栏措辞的实际压制力只有生成出来才知道。
协议：同 case 的 official_ir 与 our_ir 各喂本地 H3-Base-Ref2VA 768p，
三盲评（评者不知来源）：保真红线达成、伪影计数（嘴部/手部/文字/结尾漂移）、
叙事节奏。**成片层败而 IR 层"一致"的 case 是金矿**：说明 §3 的比对维度有盲区，
回头增补比对维度——评测体系本身也在对齐回路里。

## §5 收敛判据与毕业

- **收敛判据**：连续 20 个新探针 case，维度 1–3（任务类型/引用面/仲裁）零分歧，
  维度 4–6 分歧率 < 15%，且连续两轮无新增系统性偏差记录
- **毕业后**（可选 SFT）：训练目标 = P0–P4 裁决草稿 + 终稿的**完整链条**，
  绝不只蒸终稿——只蒸终稿得到的是形的复读机，裁决链才是可迁移的实。
  语料即 corpus 全量（our_draft 经 §3 修正后的版本作为思维链标签）。
  底座建议 Qwen3-Omni-30B-A3B（原生听音频）或 Qwen3-VL-32B（与 H3-Encoder 同源），
  QLoRA；硬件需求按所选底座与量化配置评估
- **持续义务**：官方模型/API 升级后，抽 10 个旧 case 重采，检测官方裁决漂移；
  漂移即重开对应探针族
